# Proposal

## Why

Контактов сотни, и люди в них из разных частей жизни: семья, друзья, теннис, коллеги-аналитики. Сейчас список один на всех, и чтобы найти «всех, с кем играю в теннис», приходится помнить имена. Группы позволят разложить людей по своим кругам и быстро увидеть только нужный.

## What Changes

- Группы создаёт сам пользователь, с любыми названиями: «Семья», «Теннис», «Аналитики». Название обязательно, не длиннее 50 символов, две группы с одинаковым названием (без учёта регистра) быть не может. На настоящем сайте сначала групп нет
- Контакт может быть сразу в нескольких группах или ни в одной
- В окнах «Новый контакт» и «Изменить контакт» — поле «Группы»: все группы списком с галочками и поле «Новая группа». Сохраняется вместе с контактом по «Сохранить», «Отмена» ничего не сохраняет, в том числе новые группы
- В карточке контакта — строка «Группы»: метки групп и кнопка «+». Она открывает тот же список с галочками и полем «Новая группа»; каждая галочка сохраняется сразу
- В строке контакта на главной — его группы: «Семья · Теннис». Так же в найденном поиском
- Фильтр на главной под поиском: ряд кнопок с группами. Нажал «Теннис» — в списке только контакты из этой группы, нажал ещё раз — снова все. Фильтр работает вместе с поиском, сохраняется в адресе страницы, а блок «Пора связаться», пока выбрана группа, скрыт, как при поиске
- Страница «Группы» (ссылка из ряда фильтра): все группы с числом контактов, создание, переименование и удаление. Удаление — после подтверждения; контакты остаются, просто выходят из группы
- Тестовые данные: после `pnpm db:seed` есть группы «Семья», «Друзья», «Знакомые», «Теннис», «Аналитики», часть контактов в одной или двух из них
- Автотесты: в проект подключается Vitest (он уже есть в стеке проекта). Новый код пишется через тест: сначала тест на сценарий спеки, он красный, потом код. Сценарии про данные проверяются тестами на настоящей базе в Docker. Сценарии про экраны проверяются руками в браузере, e2e-тесты на них и CI — позже, отдельной задачей
- README: что умеют группы, как запускать тесты

## Capabilities

### New Capabilities

- `contact-groups`: группы контактов — создание, переименование и удаление групп, членство контакта в группах, метки в списке и карточке, фильтр списка по группе

### Modified Capabilities

- нет

## Impact

- База: две новые таблицы — группы и связи «контакт — группа». Существующие таблицы не меняются, данные не трогаются. Одна миграция. Удаление контакта или группы удаляет их связи
- Экраны: главная — ряд фильтра по группам под поиском и строка групп в строке контакта; окна «Новый контакт» и «Изменить контакт» — поле «Группы»; карточка контакта — строка «Группы» с кнопкой «+»; новая страница «Группы»
- Список контактов, подгрузка при прокрутке и поиск учитывают выбранную группу
- Новых библиотек в приложении нет: всплывающий список в карточке — компонент Popover из shadcn/ui на уже подключённом Base UI. Для тестов — Vitest, последняя стабильная версия, только для разработки
- Локальная база: тесты работают в отдельной базе рядом с рабочей, в том же контейнере Docker. Рабочие контакты тесты не трогают
